# Bill Analyzer (FastAPI + Streamlit)

This project provides:
- `POST /bills/upload` to upload one or many PDF bills and extract:
  - owner name
  - issuer name
  - date
  - total amount
- `GET /bills/{bill_id}` to retrieve analyzed data by ID
- A Streamlit UI to upload files and display JSON responses

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Create a `.env` file with your Azure OpenAI configuration:

```env
AZURE_OPENAI_ENDPOINT=...
AZURE_OPENAI_API_KEY=...
AZURE_OPENAI_VERSION=2025-01-01-preview
AZURE_GPT4O_MODEL=...

# PostgreSQL
db_url=postgresql://<user>:<password>@<host>:5432/<database>
```

## Run FastAPI

```bash
uvicorn app.main:app --reload
```

API docs: http://localhost:8000/docs

## Run Streamlit

```bash
streamlit run streamlit_app.py
```

In Streamlit, keep `FastAPI Base URL` as `http://localhost:8000` unless your API runs elsewhere.

## Notes

- Data is stored in PostgreSQL table `bills`.
- `id` is an auto-increment integer generated by the database (`1, 2, 3, ...`).
- Extraction uses Azure OpenAI only.
